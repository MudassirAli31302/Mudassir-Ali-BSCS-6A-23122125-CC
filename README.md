## About

This project is a lexer (lexical analyzer) for the C language, made using FLEX. It reads a C source file, finds the tokens, and prints a table of tokens with a summary count at the end. It also reports errors with line numbers.

## Tokens Recognized

- Keywords: `if`, `else`, `int`, `return`, `while`, `for`, `float`, `char`, etc.
- Identifiers: names like `x`, `main`, `_count`
- Integers: `10`, `20`
- Floats: `3.14`
- Strings: `"Hello"`
- Characters: `'a'`
- Operators: `=`, `+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `++`, `--`
- Symbols: `;`, `,`, `( )`, `{ }`, `[ ]`
- Preprocessor lines: `#include`, `#define`

Spaces and comments (`//` and `/* */`) are ignored. Invalid characters, unterminated strings and unterminated comments are reported as errors.

## Files

- `lexer.l` - FLEX source file with the rules
- `input.txt` - sample code to test the lexer (contains `int`, `if` and `else`)
- `lex.yy.c` - C file generated by FLEX
- `output.txt` - output of the lexer
- `CMD SC.png` - screenshot of the output

## How to Run

1. Generate the C file:
   ```
   flex lexer.l
   ```
2. Compile it:
   ```
   gcc lex.yy.c -o lex.yy.exe
   ```
3. Run it:
   ```
   lex.yy.exe input.txt
   ```
4. Save the output to a file:
   ```
   lex.yy.exe input.txt > output.txt
   ```

Note: the folder path should not contain spaces.
